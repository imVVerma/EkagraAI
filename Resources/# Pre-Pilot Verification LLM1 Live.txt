## 2. Verify Live Mode Does Not Silently Fall Back

Inspect all LLM1 live-mode exception handling.

The deterministic fallback currently mentioned in `backend/server.py` must NOT silently substitute deterministic behavior during a controlled experiment.

Required behavior:

### Development/application mode

A deterministic fallback may remain if it is explicitly useful.

### Controlled experiment mode

If:

```text
EKAGRA_MODE=live
```

and the LLM call fails:

```text
provider failure
timeout
authentication error
rate limit
structured output error
budget error
network error
```

then:

1. record the failure
2. record the typed error
3. record usage if available
4. record the experiment/run ID
5. mark the case as failed
6. do NOT silently substitute deterministic tutor output

The pilot must measure actual LLM1 behavior.

A deterministic fallback must never be counted as successful LLM1 behavior.

If necessary, introduce an explicit configuration such as:

```text
EKAGRA_ALLOW_DETERMINISTIC_FALLBACK=false
```

with safe default behavior.

For controlled live experiments, it must be false.
