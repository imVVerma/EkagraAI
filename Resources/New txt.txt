## Diagnostic objective

This run is specifically to test the actual LLM1 pipeline now that the provider wire format works.

For every case, inspect:

### Provider

* actual provider
* actual model
* HTTP/provider success or failure
* provider request ID
* latency
* typed errors

### Structured output

Verify:

* response is returned
* JSON parses
* correct response type
* strict schema validation succeeds
* required fields are present
* no malformed output
* no schema drift

If a structured-output failure occurs, preserve the exact failure rather than loosening the schema.

### Grounding

For every successful LLM1 output, assess whether the generated content is grounded in the selected Knowledge Bank V3 context.

Flag only concrete issues such as:

* unsupported doctrinal claims
* invented Arthashastra concepts
* invented case facts
* contradictions with selected context
* irrelevant content

Do not treat stylistic variation as a grounding failure.

### State-machine authority

Verify that:

* scoring determines demonstrated SOLO level
* state machine determines progression
* checkpoint clearance remains authoritative
* retry count remains authoritative
* scenario remains authoritative
* pedagogy history remains authoritative
* LLM1 cannot advance the learner merely by declaring success

### Retry/intervention

For failing cases, verify:

* correct transition remains active
* scenario handling follows the existing rules
* an unused pedagogy is selected where required
* a new intervention/question is generated
* reassessment occurs
* no premature advancement occurs

### Logging

Verify every live record contains the required:

* experiment ID
* run ID
* provider
* model
* role
* KB release
* KB SHA
* prompt/config versions
* token usage
* cost
* latency
* success/failure
* error information
* provider request ID where available
* `kind=live`

Confirm no mock rows enter the live experiment logs.

### Cost

Report:

* total input tokens
* total output tokens
* total cost
* average cost/call
* request budget consumption
* session budget consumption
* experiment budget consumption

If a budget ceiling is reached, stop safely.
