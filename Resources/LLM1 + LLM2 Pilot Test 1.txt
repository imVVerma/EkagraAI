AGENT RESPONSIBILITIES

LLM2 is the simulated learner.

LLM2 must:

* receive only the context appropriate for the learner at that point
* maintain its simulated learner state
* follow the assigned learner profile
* generate a natural learner response
* not help LLM1
* not reveal that it is being evaluated
* not reveal the target signature merely because it knows the test condition
* not deliberately optimize for passing
* preserve mistakes when its assigned profile requires them
* improve only when an intervention genuinely addresses the learner's problem

LLM1 is the tutor.

LLM1 must:

* use Knowledge Bank V3.1 as the subject-matter source of truth
* respond naturally to the learner
* identify the evidence demonstrated by the learner
* select an appropriate pedagogy
* provide teaching/intervention when required
* ask the next question when appropriate
* stay within the current case and transition selected by the state machine
* use only supported doctrine/case material
* distinguish demonstrated understanding from merely asserted understanding

LLM1 MUST NOT:

* decide progression
* directly modify SOLO state
* declare checkpoint clearance as authoritative
* invent doctrine or case facts
* fabricate citations/provenance IDs
* manufacture evidence that the learner did not provide
* treat verbosity or sophistication as proof of a higher SOLO level
* expose internal decision traces, model names, costs, or evaluation metadata to the learner
