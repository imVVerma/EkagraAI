## Execution rules

Run the pilot as an experiment.

For each case:

1. Record the case ID and starting state.
2. Run the normal LLM1 teaching/checkpoint/respond flow.
3. Capture the actual provider response.
4. Validate the structured response against the strict schema.
5. Run the deterministic scorer/state machine.
6. Verify that LLM1 did NOT directly mutate authoritative state.
7. Record the resulting state and progression decision.
8. Record usage, latency, cost, and errors.
9. Continue to the next independent case if a case fails, unless the failure makes continuation unsafe or invalid.
10. Never convert an LLM1/provider failure into a deterministic success.
11. Never silently retry with another model/provider.
12. Do not modify prompts, schemas, scoring rules, or state-machine logic during the pilot.

Preserve failures exactly as observed. We want diagnostic evidence.
