## 1. Add Provider-Aware Model Catalogue

The current system assumes:

```text
logs/openrouter_models.json
```

for pricing/model lookup.

That must no longer be hardcoded for all providers.

Implement provider-aware catalogue resolution.

Conceptually:

```text
provider = openrouter
    → logs/openrouter_models.json

provider = groq
    → logs/groq_models.json
```

Use the existing architecture and naming conventions where possible.

Do not create a generic abstraction more complicated than necessary.

## 3. Pricing Must Be Provider-Specific

The budget system must never price a Groq request using OpenRouter pricing data.

For:

```text
EKAGRA_LLM_PROVIDER=groq
```

pricing must come from:

```text
logs/groq_models.json
```

or another explicit Groq pricing source.

For:

```text
EKAGRA_LLM_PROVIDER=openrouter
```

continue using the OpenRouter catalogue.

If pricing is unavailable:

```text
PricingUnavailableError
```

or the existing equivalent must occur.

Do not treat unknown pricing as zero.

Do not bypass the budget guard.

---
